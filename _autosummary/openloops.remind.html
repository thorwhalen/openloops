openloops.remind#

Reminders: loops kept in a store and delivered through a channel that holds the time.

The runner over openloops.loops (ADR-013). The core modules never import this one: it is where a store, a clock and a delivery channel are composed, and it is the only openloops code that sends anything for a reminder.

How a reminder survives a sleeping machine: when a loop comes within the horizon (three days, ntfy’s limit), it is armed, handed to ntfy as a scheduled message whose sequence id is the loop’s id. ntfy delivers it at remind_at whether or not this machine is awake. Done or snoozed first, the scheduled copy is cancelled or replaced by the same id, but ntfy.sh does not honour that today (UNCANCELLABLE_NOTE), so the result carries a warning that the original push may still arrive. A tick (ol remind-tick, hourly from a launchd job) arms loops that came within the horizon, records the ones that fired, and delivers late, saying so, anything that was never armed.

Three seams, each one keyword argument with a default that works:

  • store: a MutableMapping[str, Loop]; default JSON files under ~/.local/share/openloops/loops/ (loops_store()).

  • deliver: an object with schedule, now and cancel; default NtfyDelivery, through correspond’s ntfy channel (``pip install

    openloops[remind]``).

  • settings: RemindSettings; default from the environment.

Privacy. ntfy.sh is a public relay: anyone holding the topic reads the push. A push says only that a reminder is due unless the loop was made with reveal=True; the title then travels too. Reveal short labels only, never names, clients or secrets.

class openloops.remind.RemindSettings(channel='ntfy:', horizon_hours=71.0, generic_title='Reminder', generic_text='A reminder you set is due.', tz=None)[source]#

Bases: object

What the owner sets once. from_env reads OPENLOOPS_REMIND_* and OPENLOOPS_TZ.

channel is a correspond reference (ntfy: is the default topic). tz is an IANA zone for reading and echoing times; None uses the machine’s own, with its daylight-saving rules applied per instant. horizon_hours is capped at 71 (ntfy schedules three days ahead at most).

property channel_label: str#

a topic in the reference is a bearer secret.

Type:

The channel’s name only

property zone#

A ZoneInfo, or None for the machine’s own zone (see attach()).

openloops.remind.UNCANCELLABLE_NOTE = 'ntfy.sh still delivers a scheduled push that was cancelled or replaced, so the original push may arrive at {at} anyway'#

a DELETE (or a replacement under the same sequence id) of a scheduled message is acknowledged with a message_delete event, yet the original is still delivered at its time. ntfy’s documentation says otherwise; until the server honours it, an early done or snooze is said, not hidden.

Type:

Measured on ntfy.sh, 2026-11-19

openloops.loops#

Loops: the one record of a commitment, and the pure function that says what is due.

A loop is an open loop in David Allen’s sense: a commitment held somewhere other than your head. It is one record whatever GTD list it sits on, so every list (In, Next, Waiting For, Someday, the tickler) is a view over loops rather than a separate store.

Two vocabularies, kept apart on purpose (ADR-013):

  • state is the lifecycle, in A2A’s seven names, the same ones equerry’s desk Item uses, so a loop is a desk item without translation. A reminder that is scheduled is submitted with a remind_at; once it fires it is input-required; done is completed; dismissed is rejected; withdrawn is canceled.

  • list is the GTD list: in, next, waiting, someday, reference. “Scheduled” (the tickler) is not a list; it is a loop with a future remind_at.

Three times, never conflated: remind_at (when it comes back to you: the tickler, GTD’s defer date), due (a deadline, a promise to someone) and created. All are stored as UTC ISO strings.

Nothing here reads a clock, a file or the network: evaluate() takes now and returns the actions a runner should take (openloops.remind is that runner).

>>> now = datetime(2026, 11, 19, 12, 0, tzinfo=timezone.utc)
>>> loop = new_loop("Send the signed draft", remind_at=now + timedelta(hours=3), now=now, id="loop-a")
>>> loop.state, loop.list
('submitted', 'next')
>>> [a["action"] for a in evaluate([loop], now)]
['arm']

openloops.loops.evaluate(loops, now, *, horizon=datetime.timedelta(days=2, seconds=82800))[source]#

What a runner should do now, as data. Pure: same loops and now, same actions.

For each open, accepted loop with a remind_at:

  • arm: due within horizon and not yet handed to the channel at that time. The channel delivers it at remind_at even if this machine is asleep then.

  • deliver: due and never armed (created late, or arming failed, or the machine slept past the horizon). Sent now, saying how late.

  • woke: due and armed, so the channel has delivered it; the loop now needs its owner (input-required).

  • disarm: closed but still armed, or moved (snoozed) outside the horizon while armed at its old time: cancel the channel’s copy.

Proposals (proposed_by set) never produce a delivery.

>>> now = datetime(2026, 11, 19, 12, 0, tzinfo=timezone.utc)
>>> far = new_loop("x", remind_at=now + timedelta(days=5), now=now, id="far")
>>> late = new_loop("y", remind_at=now - timedelta(minutes=5), now=now, id="late")
>>> [(a["action"], a["id"]) for a in evaluate([far, late], now)]
[('deliver', 'late')]

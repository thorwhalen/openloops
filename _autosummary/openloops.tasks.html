openloops.tasks#

Everything you could act on, as one list of task records: gather, classify, merge.

openloops.owed() answers “what do I owe, and is it still owed?” for one label. A task board needs a wider net and a different answer: every open item across a fleet that asks something of the human (the manual-task issues, the issues titled “Decide…”, the PRs waiting on their review), each turned into a task record saying what to do, where to do it, how long it takes and on which device.

Three steps, each a plain function:

  1. gather() sweeps several owners with gh search, one query per owner and kind so no owner’s results crowd out another’s, with no 50-row cap (the search API’s own ceiling of 1000 per query is the limit, and a query that reaches it is reported as saturated, never truncated quietly). Exclusions are keyword arguments.

  2. classify() turns each candidate into a record through a classifier=. The default, heuristic_classify(), is deterministic: label, title and body patterns decide the tier, the pattern and the minutes, and the deep-link builders point at the exact settings page. No model is called, here or anywhere in openloops. The richer path is the classifier brief shipped with the openloops-phone-board skill: a subagent reads each item and writes records in the same schema, which merge_records() lays over the heuristic ones.

  3. merge_records() combines record sources by URL, later sources winning, and normalises every record to TASK_FIELDS.

The record schema is Task, defined once, here. The board page, the build step and the classifier brief all read it; a field added anywhere else is a field the others do not know about.

Read-only, like the rest of openloops. Gathering runs gh search; nothing here comments, closes, labels or approves anything.

>>> candidate = {
...     'url': 'https://github.com/acme/widget/issues/7', 'repo': 'acme/widget',
...     'number': 7, 'title': 'Add the NPM_TOKEN secret so CI can publish',
...     'body': '', 'labels': ['manual-task'], 'created': '2026-08-01',
... }
>>> record = heuristic_classify(candidate)
>>> record['tier'], record['pattern'], record['id']
('browser', 'github-settings', 'acme/widget#7')
>>> [link['label'] for link in record['links']]
['GitHub: Actions secrets', 'Issue']

openloops.tasks.gather(*, owners=None, exclude_owners=(), exclude_repos=None, label='manual-task', searches=(), review_prs=False, limit=1000, timeout=30.0, run_gh=None)[source]#

Every open item that asks something of the human, across owners, deduplicated.

One query per owner and per kind: the label (manual-task), each named search in searches (keys of DFLT_SEARCHES), and with review_prs the open PRs requesting your review. owners defaults to openloops.obligations.configured_owners(); exclude_repos (owner/name globs) defaults to OPENLOOPS_EXCLUDE_REPOS. run_gh replaces the gh runner (run_gh(args, timeout=...) -> stdout).

The result is an envelope: listed is False with an error when any query failed, because a partial sweep presented as a whole one is the failure that matters. saturated names the queries that hit limit.

>>> def fake(args, *, timeout):
...     return json.dumps([{'number': 1, 'title': 'Add a key',
...         'url': 'https://github.com/acme/w/issues/1',
...         'repository': {'nameWithOwner': 'acme/w'}, 'labels': [], 'body': ''}])
>>> report = gather(owners=['acme'], run_gh=fake)
>>> report['listed'], [c['id'] for c in report['candidates']]
(True, ['acme/w#1'])

A task record from a gathered candidate, by patterns alone. No model, no network.

rules are tried in order against the title and body; machines maps an owner to the machine its session-tier prompts name. Status is always open: whether an ask was already done is a judgement only a reader of the thread can make (the classifier brief’s job).

>>> pr = {'url': 'https://github.com/acme/w/pull/3', 'repo': 'acme/w',
...       'title': 'Bump lodash from 4.17.20 to 4.17.21', 'body': ''}
>>> heuristic_classify(pr)['pattern'], heuristic_classify(pr)['links'][0]['url']

openloops.tasks.merge_records(*sources)[source]#

Records from several sources, one per item, later sources winning.

Keyed by id (derived from the URL for a GitHub item, so the two sources agree); a record with no id and no URL is dropped. A later record replaces the earlier one whole, except that an empty url or created is filled from it: the classifier brief reads threads, the gatherer knows dates.

>>> heuristic = [{'id': 'a/b#1', 'url': 'u1', 'tier': 'browser', 'created': '2026-01-02'}]
>>> enriched = [{'id': 'a/b#1', 'url': 'u1', 'tier': 'tap', 'ask': 'Say yes'}]
>>> [(r['tier'], r['ask'], r['created']) for r in merge_records(heuristic, enriched)]
[('tap', 'Say yes', '2026-01-02')]
Return type:

list[dict[str, Any]]

openloops.board_refresh#

Keep the phone board within a day of GitHub, without a session remembering to.

The board (openloops.board) is built by hand once: gather, classify, build. Left alone it goes stale (a board built 2026-10-27 was still that build on 2026-11-09, with 210 of its 420 cards closed and 222 new items missing). refresh_board() is the rebuild as one deterministic, model-free step meant to run from a timer (ol install-refresh-job) or by hand (ol board-refresh WORK):

  1. gather the open items (openloops.tasks.gather()) over the scope saved in WORK/refresh.json (flags given on the command line are saved there first, and what OPENLOOPS_OWNERS/OPENLOOPS_EXCLUDE_REPOS or the default owners resolve to is saved as explicit lists, so a timer without that environment sweeps the same scope: pin_env_scope());

  2. merge them with the live WORK/board/tasks.json (merge_refresh(), pure): the earlier record of every id still open is kept, with its title and url refreshed from GitHub and nothing re-classified; each new id gets the free heuristic record;

  3. if nothing opened, closed or was retitled, stop (rebuilt: False);

  4. otherwise rebuild into a temporary directory and move each file into place (os.replace: the receiver job reads tasks.json at any moment); the new ids accumulate in WORK/new-items.json for a session’s classifier brief;

  5. publish (a directory, or host:dir through scp) whenever the local board’s files differ from the last ones published, and only then record it.

Guards, because a wrong rebuild is worse than a stale one:

  • an incomplete sweep (listed: false) never rebuilds;

  • a saturated sweep (some search hit its cap) adds but never closes;

  • closing more than max_close_fraction of a board of at least GUARD_MIN_LIVE cards is refused unless force: those closes are withheld

    (and named in refresh.json), while additions and retitles still go through, so a refusal never freezes the board;

  • a tasks.json, board.json or refresh.json that exists but does not parse (or, for refresh.json, holds a value of the wrong shape) raises rather than being read as empty, and a first run with no board.json raises rather than publishing default settings;

  • an owner-edited kit.html (one that differs from the packaged template) is kept.

A board whose page keeps its state in a claude.ai Artifact cannot be republished from here: the result says needs_republish: True and a session republishes it.

What it touches: GitHub through gather (read-only); files under WORK; and, when publishing, the destination directory or the remote host (scp with the user’s own keys). It never calls a model.

openloops.board_refresh.dir_publisher(destination, *, timeout=300)[source]#

A publisher that copies the board’s files to destination.

destination is a directory, or host:dir (see is_remote_destination()), which goes through scp -o BatchMode=yes (never a password prompt that would hang a timer) with timeout seconds. A local copy replaces each file atomically; the remote copy does not (scp writes in place), so a reader on the host can, for a moment, see a partly written file. A failure raises, so a timer’s log says the board did not move.

Return type:

Callable[[Path], None]

openloops.board_refresh.is_remote_destination(destination)[source]#

Whether destination names host:dir (for scp) rather than a local path.

Remote only when the text before the first colon is a plausible host (non-empty, no / or \, not a one-letter Windows drive such as C:) and the whole thing is not an existing local path.

>>> [is_remote_destination(d) for d in ('tw:/srv/board', 'me@host:board')]
[True, True]
>>> [is_remote_destination(d) for d in (r'C:\Users\x\dest', '/tmp/a:b', 'board')]
[False, False, False]

openloops.board_refresh.merge_refresh(live, candidates, *, saturated=(), withhold_closes=False)[source]#

The rebuild’s records, the new candidates, and the plan. No I/O.

Every id still open keeps its earlier record (never re-classified), with REFRESHED_FIELDS taken from the sweep; new ids get the heuristic record. A saturated sweep did not list everything, so an id it did not see is kept (withheld), never closed; withhold_closes does the same for a sweep whose closes were refused.

>>> live = [{'id': 'a/b#1', 'title': 'Old', 'ask': 'ENRICHED'}, {'id': 'a/b#2'}]
>>> seen = [{'id': 'a/b#1', 'title': 'New', 'url': 'https://github.com/a/b/issues/1'}]
>>> records, fresh, plan = merge_refresh(live, seen)
>>> [(r['id'], r['title'], r['ask']) for r in records], plan.closed, plan.updated
([('a/b#1', 'New', 'ENRICHED')], ('a/b#2',), ('a/b#1',))
>>> records, _, plan = merge_refresh(live, seen, saturated=['label:manual-task'])
>>> [r['id'] for r in records], plan.closed, plan.withheld
(['a/b#1', 'a/b#2'], (), ('a/b#2',))

tuple[list[dict[str, Any]], list[dict[str, Any]], RefreshPlan]

openloops.board_refresh.pin_env_scope(work_dir, *, environ=None, resolve_owners=None)[source]#

Save what the environment makes the sweep’s scope into WORK/refresh.json.

A launchd timer does not get the shell’s OPENLOOPS_OWNERS or OPENLOOPS_EXCLUDE_REPOS, so a scope that lives only there would make the timer sweep a different set of repositories than a run by hand (and could put an excluded client repo on the board). Each is written as an explicit list, but only where refresh.json has no value yet (a flag given earlier, or an earlier pin, wins). With no OPENLOOPS_OWNERS, resolve_owners (e.g. openloops.obligations.configured_owners()) supplies the default owners; when it is not given they stay unset here and the first sweep’s resolved owners are pinned instead. Returns what was saved.

>>> import tempfile
>>> with tempfile.TemporaryDirectory() as tmp:
...     env = {'OPENLOOPS_OWNERS': 'me, org', 'OPENLOOPS_EXCLUDE_REPOS': 'org/x-*'}
...     first = pin_env_scope(tmp, environ=env)
...     second = pin_env_scope(tmp, environ={'OPENLOOPS_OWNERS': 'other'})
>>> first, second
({'owners': ['me', 'org'], 'exclude_repos': ['org/x-*']}, {})
Return type:

dict[str, list[str]]

openloops.board_refresh.refresh_board(work_dir, *, owners=None, exclude_owners=None, exclude_repos=None, searches=None, review_prs=None, run_specs=None, run_extras=None, publish_to=None, force=False, max_close_fraction=0.5, publish=None, gather=<function gather>, settings=None)[source]#

Rebuild WORK/board when the set of open items changed. Returns what happened.

The scope keywords (owners to publish_to) are saved into WORK/refresh.json when given and read from it when not (remember_scope()); their defaults are every kind of item and PRs awaiting review, like board-gather --all-kinds. run_specs/run_extras are passed to every rebuild, as board-build takes them. force rebuilds even when nothing changed and overrides the close guard (never the incomplete-sweep one). What the environment sets (OPENLOOPS_OWNERS, OPENLOOPS_EXCLUDE_REPOS) and, failing that, the owners the sweep resolved, are pinned into refresh.json where it has no value yet (pin_env_scope()). publish replaces the publisher built from publish_to (see dir_publisher()); gather replaces the sweep; settings override the existing board.json (and are required when there is none).

status is rebuilt, unchanged, incomplete, partial (rebuilt with additions/retitles while a mass close was refused) or refused (a mass close was refused and nothing else changed). Refused closes are withheld, never dropped: refused_closes (a count) and refused_close_ids are returned and kept in refresh.json until a run no longer refuses, and remedy is the command that applies them. A publish failure raises PublishError after the local rebuild is in place.

>>> import tempfile
>>> item = {'id': 'a/b#1', 'url': 'https://github.com/a/b/issues/1',
...         'repo': 'a/b', 'title': 'Add a key', 'src': 'label:manual-task'}
>>> sweep = lambda **kw: {'listed': True, 'candidates': [item], 'error': None}
>>> with tempfile.TemporaryDirectory() as tmp:
...     first = refresh_board(tmp, gather=sweep, settings={'title': 'Mine'})
...     again = refresh_board(tmp, gather=sweep)
>>> first['rebuilt'], first['added'], again['status']
(True, 1, 'unchanged')
Return type:

dict[str, Any]
